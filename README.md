# ☕ Coffee Shop Sales Dashboard | Excel, SQL & Power BI

## 📌 Project Overview

This project presents an **end-to-end Coffee Shop Sales Dashboard** created using **Microsoft Excel, SQL, and Power BI**.

The dataset was collected from an online source containing coffee shop sales transactions, products, categories, quantities, revenue, and related business information.

The objective of this project was to transform raw sales data into meaningful business insights through data cleaning, analysis, KPI creation, and interactive dashboard development.

## 📊 Project Workflow

### 1. Data Collection

* Obtained Coffee Shop sales dataset from an online source.

### 2. Data Cleaning & Preparation

* Sorted and organized the dataset using **Microsoft Excel**.
* Removed inconsistencies and prepared data for analysis.
* Created **Pivot Tables** and **Pivot Charts** for summarizing sales information.

### 3. SQL Analysis

* Used SQL queries to analyze the dataset.
* Performed filtering, grouping, and aggregation operations.
* Extracted business insights from sales data.

### 4. Power BI Dashboard

* Imported processed data into Power BI.
* Built an interactive dashboard.
* Designed KPIs to track overall business performance.
* Created visualizations for better decision-making.

---
